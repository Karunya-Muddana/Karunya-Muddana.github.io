Agent workbench · Smart India Hackathon 2026 · Apache 2.0

Native

An agent you run yourself. It reads your documents, executes Python in a network-disabled Docker container, searches a knowledge base that never leaves the machine, and writes the .docx, .xlsx and .pptx files you actually have to hand over — then reopens each one and reports its real contents back from disk.

Every role is a chain, not a choice. When a free tier rate-limits, the run doesn’t stop — it walks down to the next link, and the last link is a model on your own hardware with no quota at all.

MCP server · Open source · MIT

ExcelMCP

A live Excel intelligence layer for AI agents. Point it at a OneDrive folder and an agent can ask questions about those spreadsheets in plain English — against the numbers that are in them right now, not a copy taken last Tuesday.

Most spreadsheet integrations embed your cells into a vector store and answer from that snapshot. This one splits the problem: structure is cached, data never is. Every response carries a fetched_at stamp and is_cached: false, so the model can see in-band that the number is fresh.

Question→Embed→Lexical rerank→Live Graph fetch→pandas

Answers come back with provenance — file, sheet, cell. When two sheets disagree it returns conflict rather than picking one, and a query matching nothing returns diagnostics instead of a confident empty set. The setup wizard detects and configures 12 agent hosts, backing up whatever was there first.
