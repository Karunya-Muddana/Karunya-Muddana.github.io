Open source — shipped and public.

ExcelMCP — live Excel intelligence layer for agents

github ↗
  • 11 MCP tools over a OneDrive workspace. Structure is cached; no value ever is. Every response carries fetched_at and is_cached: false so the model can see in-band that the number is fresh.
  • Questions route by embedding similarity reranked on lexical overlap with column names and sampled values — which is what keeps routing meaningful when twenty workbooks share one schema.
  • lookup never returns a bare number: it returns provenance, and surfaces ambiguous and conflict outcomes instead of silently picking one. Zero-match queries return diagnostics rather than an empty set.
  • Setup wizard detects and configures 12 agent hosts (Claude Code, Cursor, Windsurf, Codex, Zed and others), backing up existing configs first. MIT, v0.3.0, listed on Glama.
Python · FastMCP · MS Graph API · FastEmbed · NumPy cosine search · Pandas · MSAL · pytest

Native — local-first multi-provider agent

github ↗
  • 22-tool LangGraph agent. Reads PDFs, scans, spreadsheets and images; runs Python in a network-disabled, memory-capped Docker container; authors .docx / .xlsx / .pptx.
  • Every written file is reopened and summarised from disk, not from the code that wrote it — so the report describes what actually landed.
  • Each model role is an ordered chain (Groq → Gemini → OpenRouter → NVIDIA NIM → local Ollama). Rate limits, retired models and timeouts advance the chain instead of ending the run.
  • Knowledge base and memory embedded locally, so documents never leave the machine whichever provider answers. Apache 2.0.
Python · LangGraph · FastAPI · Docker · PP-OCRv4 (ONNX) · RAG · Ollama · python-docx · openpyxl · python-pptx

Project Smith — zero-trust agent runtime

github ↗
  • Compiler-runtime split: natural language is compiled to a validated JSON DAG before any tool executes, which makes infinite loops structurally impossible rather than merely unlikely.
  • 4 versions in 4 months. v4.0 adds voice (Whisper + MeloTTS), a fabrication guard, long-term RAG memory, 15 tools, and a coordinator for parallel multi-agent runs. Native grew out of this.
